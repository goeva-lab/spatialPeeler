API reference#

spatialpeeler.run_fact_reg(adata, y_key, ctl_val, k, out_key, X_key='X_nmf', filt=None, fit_args=None)[source]#

executes the first step of the spatialPeeler pipeline by:

  • running a logistic regression on condition labels w/ a one-dimensional embedding subspace + intercept as model inputs

  • adding per cell outputs to input .obsm slot

  • adding model coefficients, p-values, mean standard error, and cross-entropy loss values to input .uns slot

Parameters:

  • adata (AnnData) – input data, must not be a view, will be mutated

  • y_key (str) – .obsm key to fetch condition labels from

  • ctl_val (object) – condition label corresponding to control

  • k (int) – dimension of embedding to analyze

  • out_key (str) – key used to insert outputs into input adata, will be added to both .uns and .obsm

  • X_key (str) – adata .obsm key to fetch embeddings from, defaults to "X_nmf"

  • filt (Callable[[AnnData], AnnData] | None) – optional callable to subset data prior to running step, defaults to None

Raises:

ValueError – if input adata is a view

Return type:

None

spatialpeeler.run_gene_reg(adata, sp_step1_key, out_key, run_reg=True, run_corr=True, layer=None)[source]#

runs the second step of the spatialPeeler process by:

  • computing correlations between spatialPeeler outputs and gene expression

  • computing regression-based (via OLS) differential expression analyses between spatialPeeler outputs and gene expression

  • adding resulting outputs to the input .varm slot

Parameters:

  • adata (AnnData) – input data, already processed by run_fact_reg(), must not be a view, will be mutated

  • sp_step1_key (str) – .obsm key used by run_gene_reg() to store its outputs

  • out_key (str) – .varm key used to store outputs

  • layer (str | None) – optional, layer to use to fetch gene counts instead of .X, defaults to None

Raises:

ValueError – if input adata is a view

Return type:

None
